# Brain In A Box

> **Roxxy, c'est ma « Brain In A Box ».** C'est ma Jarvis personnelle : la structure universelle qui sert de modèle pour construire mon application.

Cette section rassemble le concept fondateur de tout le système. Toutes les conversations et tous les documents produits avec des outils d'IA sont, au fond, **de la mémoire pour Alyson Virtuelle**. Avant de les verser, on construit la structure organisationnelle qui va les traiter.

## Les 4 espaces
| Espace | Ce qu'on y trouve |
| --- | --- |
| `01_Concept fondateur` | Le projet maître : vision, objectifs, livrables. Source : [[Diagramme-évolutif-demandé]] |
| `02_Structure universelle` | Le modèle réplicable de toute agente IA (identité, mémoire, gouvernance, travail…) |
| `03_Roxxy — Second cerveau` | Roxxy, ses bases de données (le second cerveau) et ses documents source de vérité |
| `04_Mémoire à trier` | Les conversations et documents d'IA à verser, un à la fois, une fois la structure prête |

## Le lien avec Alyson Virtuelle
- La **structure universelle** s'applique d'abord à Alyson Virtuelle.
- Les **bases de Roxxy** forment le second cerveau d'Alyson.
- Le **chat de Smart Second Brain** servira à parler directement à Alyson Virtuelle. Elle est conçue comme la réplique de Claude : tout ce qu'on fait aujourd'hui en dehors du coffre, c'est ce qu'elle ne peut pas encore faire de l'intérieur.
