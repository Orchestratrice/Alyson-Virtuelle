# Structure universelle d'agente

Le gabarit que chaque agente reçoit, quelle que soit sa spécialité. Il vient du [[Diagramme-évolutif-demandé]] ; il reste « À valider » tant qu'Alyson ne l'a pas confirmé.

| Niveau | Bases |
| --- | --- |
| 1. Noyau identitaire (obligatoire) | Identité · Rôle · Soul (âme) |
| 2. Connaissances | Skills · Domaines d'expertise · Bibliothèque de connaissances |
| 3. Mémoire | Mémoire long terme · Mémoire court terme · Journal de bord · Historique des décisions |
| 4. Gouvernance | Responsabilités · Autorisations · Politiques |
| 5. Travail | Tâches · Projets · Objectifs (OKR) |
| 6. Processus | Processus · SOP (procédures) |
| 7. Automatisation | Automatisations · Outils |
| 8. Cognition | Prompt système · Cadre décisionnel · Frameworks |
| 9. Apprentissage | Feedback · Leçons apprises · Évolution |
| 10. Réseau interne | Relations inter-agentes · Communications |

## Version minimale (pour commencer)
Identité, Rôle, Soul, Skills, Mémoire long terme, Journal de bord, Responsabilités, Tâches.
