# Index des connaissances

Aucune connaissance thématique n’est encore enregistrée.

## Convention proposée

Chaque connaissance future devrait indiquer :

- un titre précis ;
- le domaine ;
- le statut (`vérifié`, `hypothèse`, `à confirmer`) ;
- la source ;
- la date d’ajout ou de révision ;
- les liens vers les connaissances associées.
