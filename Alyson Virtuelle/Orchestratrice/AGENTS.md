# Règles d’Orchestratrice

## Périmètre

Ce dépôt est un espace isolé et dédié à une seule instance documentaire. Il ne faut pas le mélanger avec les autres dépôts, vaults, plugins, projets ou historiques de conversation.

## Sources autorisées

1. Les fichiers présents dans ce dépôt.
2. Les décisions explicitement consignées dans `04-decisions/`.
3. Les connaissances ajoutées avec une source ou un statut clairement indiqué.
4. Les instructions explicites données pour Orchestratrice.

## Sources exclues par défaut

Les autres répertoires de `/data/workspace`, les autres dépôts GitHub, les notes Obsidian et les anciennes conversations ne font pas partie de ce projet par défaut.

## Discipline documentaire

- Ne pas inventer de faits, de souvenirs ou de capacités.
- Séparer les faits vérifiés, les hypothèses et les questions ouvertes.
- Préserver l’historique des décisions importantes.
- Ne jamais stocker de secrets, clés API, mots de passe ou tokens.
- Utiliser des noms de fichiers stables et explicites.
- Vérifier les documents après chaque modification importante.

## Évolution

Toute nouvelle convention structurelle doit être ajoutée à la documentation du noyau ou à un document de décision avant d’être considérée comme acquise.
